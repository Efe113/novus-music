# Novus Music — Dağıtım

Kişisel Windows müzik çaların kurulum dosyaları bu deponun **Releases** bölümünde yayınlanır.

- İndirme: en güncel [Release](https://github.com/Efe113/novus-music/releases/latest) sayfasındaki `NovusMusic-Setup-x.y.z.exe`
- Uygulama, güncellemeleri `update.json` üzerinden denetler ve kurulum dosyasını uygulama içinde indirip SHA-256 ile doğrular.

Kaynakları yalnızca kişisel kullanım için indirin.
